# Draw

A small, standalone drawing canvas built with TypeScript, webpack and the browser Canvas 2D API. No framework, backend, or persistence.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

For production: `npm run build`. Serve `public/index.html` and `public/style.css` along with `dist/app.js` from the same site root. The app uses root-relative asset paths.

Tools: pen, marker, glow, spray, fill, eraser and clear. Touch and mouse supported.
